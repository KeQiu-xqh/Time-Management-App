# 任务预估时长设计

## 目标

为每个任务增加可选的预估总时长，输入使用小时和分钟组合，展示统一换算为小时小数，同时不影响日历中已有的单次时间块长度。

## 数据与规则

- 新字段 `estimatedDuration?: number`，单位为整数分钟。
- 接受 `2h40min`、`2h`、`40min`，忽略大小写和空格。
- 小时与分钟组合时，分钟部分必须为 0–59；仅分钟输入可超过 59，例如 `160min`。
- 空值代表未填写；零、负数、小数、秒和其他文本无效。
- 展示值保留最多两位小数并去除末尾零：160 分钟显示 `2.67h`，90 分钟显示 `1.5h`，120 分钟显示 `2h`。

## 界面

- 新建与编辑任务表单始终显示“预估时长（可选）”。
- 默认列表卡片和周列表紧凑卡片显示预估时长。
- 桌面待办池与手机任务详情显示预估时长。
- 任务第一次获得具体开始时间且尚无日程时长时，用 `estimatedDuration` 初始化卡片长度；若会跨过午夜，则截到 24:00。
- 用户之后拖动或缩放得到的 `duration` 优先保留，且不会反向修改 `estimatedDuration`。

## 验收

- 新旧任务数据兼容，未填写时不显示。
- 输入解析和小时格式化具有边界测试。
- TypeScript、全部测试、生产构建和 Vercel 在线资源检查通过。
