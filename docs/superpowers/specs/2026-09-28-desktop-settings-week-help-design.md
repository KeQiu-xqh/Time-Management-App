# 桌面端设置与七日日程优化设计

## 目标

1. 设置弹窗在桌面端始终留在可视区域内，标题固定，正文可滚动到底。
2. 桌面端周列表无需横向移动即可同时看到周一至周日。
3. 设置页用普通用户语言解释微信与 OneDrive 尚未开通的原因，不暴露环境变量名。
4. 设置页提供可访问的问号帮助按钮，点击展开本地数据、备份、登录和同步说明。

## 交互设计

- 所有通用弹窗在桌面端使用 `100dvh - 32px` 最大高度和纵向 flex 布局；标题栏不滚动，正文独立滚动。
- 周列表取消 800px 强制最小宽度，使用七个 `minmax(0, 1fr)` 等宽列。列间距、卡片内边距和右侧待办池在中等桌面宽度下收紧。
- 设置页“个人资料”标题右侧放置圆形 `?` 按钮。按钮具备 `aria-expanded` 和 `aria-controls`，再次点击可收起说明。
- 帮助内容分为“数据保存”“跨端同步”“微信登录”三段，并明确同步口令无法找回、首次同步前应导出备份。
- 未配置提示显示“站点尚未开通”，具体管理员变量只保留在 README，不展示给普通用户。

## 配置边界

- 代码可以检测缺失配置、禁用不可用操作并展示说明。
- OneDrive 客户端 ID 必须由 Microsoft 应用注册生成。
- 微信公众号 Token、二维码和 Upstash 地址必须来自对应外部账户，不能安全地硬编码或自动伪造。

## 验收

- 账号弹窗在 768px 及以上视口内可滚动到版本信息和危险区域。
- 周列表源码不再包含 `min-w-[800px]`，七列容器不产生主动横向滚动。
- 帮助按钮和三段说明可通过键盘与屏幕阅读器识别。
- 缺少外部配置时按钮保持禁用，页面不显示环境变量名。
- TypeScript、全部测试和生产构建通过。
